# Backlog

Working list of bugs, fixes and ideas for BIM Nexus. Product direction lives in `Roadmap.md`; this file is the day-to-day list.

Format: `area | item | type (bug / small fix / feature / UI) | status (open / in progress / done)`

Small fixes go straight to Claude Code. Features and schema changes go through a superpowers spec, then a plan.

## Decisions

- 2026-11-12 SQLite uses transaction_mode IMMEDIATE with a 20s timeout and no WAL, because rollback.ps1 copies only the main database file.
- 2026-11-12 /media/ requires login; media is backed up to the share with robocopy /E, never /MIR.
- 2026-11-12 Signatures will be stored in the database, not in media, and are append-only.
- 2026-11-14 Production secret key replaced; run_production.py refuses the development default and DEBUG=true.
- 2026-11-14 Daily backups run from deploy\backup.ps1 at 13:00 and 23:00 as db_prod_daily_*, keeping 28, copied to the share with media. The old "BIMNexus Nightly DB Backup" task is disabled; its 12 backups are archived in backend\backups\nightly-archive-20261114.
- 2026-11-14 Password setup links are generated in Django admin and sent by hand; the app does not send email.
- 2026-11-19 Generic serials are generated by the backend and flagged (serial_is_generated); pickers take them by quantity, oldest first. Rehearsed on a production copy: 101 of 198 units flagged, no near-misses.
- 2026-11-19 Every record list row and every reference to a record, product, unit, supplier or client links to its detail page (see DesignSystem.md).
